      When Python is turned into pseudocode, DECLARE statements and parameter types are worked out from the code (type hints are used when present), snake_case names become PascalCase, and names in CAPITALS given a single value become constants. Pseudocode arrays usually start at index 1, so Python lists get one extra element and index 0 is not used.
